Technology that enables software and systems to perform tasks that typically require human intelligence.

A decentralized digital ledger used to record transactions and other on-chain data.

## Ethereum

A blockchain network supporting smart contracts and decentralized applications.

## ERC-20

A widely used token standard for creating fungible tokens on Ethereum.

A blockchain-based program that defines and executes specified token or application functions.

A broad term describing decentralized internet technologies built around blockchain and user-controlled digital assets.

An application that uses blockchain infrastructure and smart contracts as part of its functionality.

## Digital Connectivity

The ability of digital systems, applications, and infrastructure to communicate and interact with each other.

Technology systems and services that support digital applications, connectivity, and data-driven operations.

## Developer Tools

Software and resources designed to help developers build, test, integrate, and maintain digital or blockchain applications.

A software or hardware tool that allows users to manage blockchain assets and interact with decentralized applications.

## Token Supply

The total number of tokens created for a particular asset.

## Decimals

The number of decimal places used to represent a token's smallest units.

## Liquidity

Assets available within a trading pool or market to facilitate buying and selling.

## Ecosystem

The collection of users, applications, services, developers, and infrastructure associated with a project.

## Mainnet

The live production blockchain network where real transactions are processed.
